# ChatList

Приложение для сравнения ответов различных нейросетей. Отправляйте один промт в несколько моделей одновременно и сравнивайте их ответы.

## Возможности

- 📝 Отправка одного промта в несколько нейросетей одновременно
- 💾 Сохранение промтов и результатов в базе данных SQLite
- 🔍 Поиск и сортировка по всем таблицам
- 📊 Временная таблица результатов с возможностью выбора для сохранения
- 📤 Экспорт результатов в Markdown и JSON
- ⚙️ Управление моделями нейросетей через интерфейс
- 📝 Логирование всех запросов
- 🎨 Удобный графический интерфейс на PyQt5

## Поддерживаемые модели

- OpenAI (GPT-4, GPT-3.5 и др.)
- DeepSeek
- Groq
- OpenRouter (доступ к множеству моделей через один API)

## Требования

- Python 3.11+
- PyQt5
- requests
- python-dotenv
- SQLite (встроен в Python)

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости:
```powershell
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта и добавьте ваши API ключи:
```env
OPENAI_API_KEY=sk-your-key-here
DEEPSEEK_API_KEY=sk-your-key-here
GROQ_API_KEY=gsk_your-key-here
OPENROUTER_API_KEY=sk-or-your-key-here
```

4. Запустите приложение:
```powershell
python main.py
```

## Использование

### Первый запуск

1. При первом запуске программа автоматически создаст базу данных `chatlist.db`

2. Добавьте модели нейросетей:
   - Перейдите в меню **Настройки → Управление моделями**
   - Нажмите **Добавить**
   - Заполните форму:
     - **Название**: например, "GPT-4"
     - **API URL**: URL API endpoint (например, `https://api.openai.com/v1/chat/completions`)
     - **API ID**: имя переменной из `.env` файла (например, `OPENAI_API_KEY`)
     - **Активна**: включите, если модель должна использоваться по умолчанию

### Работа с промтами

1. **Ввод нового промта**:
   - Введите текст запроса в поле "Ввод промта"
   - При необходимости добавьте теги (через запятую)
   - Нажмите **Сохранить промт** для сохранения в БД

2. **Выбор сохраненного промта**:
   - Выберите промт из выпадающего списка или
   - Дважды кликните по промту в таблице "Сохраненные промты"

3. **Отправка запроса**:
   - Введите или выберите промт
   - Нажмите **Отправить запрос**
   - Программа отправит запрос во все активные модели
   - Результаты появятся в таблице "Результаты"

### Работа с результатами

1. **Временная таблица результатов**:
   - После отправки запроса результаты отображаются во временной таблице
   - Отметьте чекбоксами результаты, которые хотите сохранить
   - Нажмите **Сохранить выбранные** для сохранения в БД

2. **Просмотр сохраненных результатов**:
   - Перейдите на вкладку **"Сохраненные результаты"**
   - Используйте поиск для фильтрации результатов

3. **Экспорт результатов**:
   - В меню **Файл → Экспорт результатов** выберите формат (Markdown или JSON)
   - Или используйте кнопки экспорта на вкладке "Сохраненные результаты"

### Настройки

- **Настройки приложения**: меню **Настройки → Настройки приложения**
  - Таймаут запросов (по умолчанию 30 секунд)
  - Максимум повторных попыток (по умолчанию 3)

## Структура проекта

```
ChatList/
├── main.py              # Основной модуль с GUI
├── db.py                # Работа с базой данных SQLite
├── models.py             # Логика работы с моделями
├── network.py           # Отправка запросов к API
├── export.py            # Экспорт данных
├── logger.py            # Логирование
├── requirements.txt     # Зависимости
├── build.ps1            # Скрипт сборки исполняемого файла
├── .env                 # API ключи (создайте сами)
├── chatlist.db          # База данных (создается автоматически)
└── logs/                # Логи приложения (создается автоматически)
```

## Сборка исполняемого файла

Для создания исполняемого `.exe` файла:

```powershell
.\build.ps1
```

Исполняемый файл будет создан в папке `dist\`.

## Логирование

Все запросы к API логируются в файлы:
- `logs/chatlist.log` - общий лог приложения
- `logs/requests.log` - детальный лог всех запросов

## База данных

Приложение использует SQLite для хранения данных:
- **prompts** - сохраненные промты
- **models** - настройки моделей нейросетей
- **results** - сохраненные результаты
- **settings** - настройки приложения
