ChatList

Один промт — несколько нейросетей. Сравнивайте ответы в одном окне.

Скачать для Windows последняя версия Исходный код на GitHub

Возможности

Один промт — все модели. Отправляйте запрос в OpenAI, DeepSeek, Groq, OpenRouter одновременно.
Сохранение и поиск. Промты и результаты хранятся в SQLite, удобный поиск и сортировка.
Экспорт. Выгрузка результатов в Markdown и JSON.
Управление моделями. Добавление и настройка API через интерфейс, ключи в .env.
Удобный интерфейс. PyQt5, тёмная/светлая тема, настройка шрифтов.

Требования

  • Windows 10/11
  • Для портативной версии — только скачать .exe
  • Для установки — запустить установщик ChatList-*-setup.exe
